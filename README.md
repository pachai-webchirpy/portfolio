# Sreesanth C — Mechatronics Portfolio 🤖

Animated portfolio website built with pure HTML, CSS & JavaScript.

## 🚀 Deploy to Vercel (Step-by-Step)

### Method 1: GitHub + Vercel (Recommended)

**Step 1 — Push to GitHub:**
1. Go to [github.com](https://github.com) → Sign in → Click **"New repository"**
2. Name it `portfolio` (or any name you like)
3. Keep it **Public** → Click **"Create repository"**
4. Upload the files from this folder:
   - Click **"uploading an existing file"** link
   - Drag & drop **all 4 files** (`index.html`, `package.json`, `vercel.json`, `README.md`)
   - Click **"Commit changes"**

**Step 2 — Deploy on Vercel:**
1. Go to [vercel.com](https://vercel.com) → Click **"Sign Up"** → Sign in with **GitHub**
2. Click **"Add New Project"**
3. Find your `portfolio` repo → Click **"Import"**
4. Leave all settings as default → Click **"Deploy"**
5. Wait ~30 seconds ⏳ → Your site is LIVE! 🎉

Your URL will be: `https://portfolio-yourusername.vercel.app`

### Method 2: Vercel CLI (For advanced users)

```bash
npm install -g vercel
cd portfolio-vercel
vercel
```

Follow the prompts and your site will be live!

### Method 3: Drag & Drop (Fastest)

1. Go to [vercel.com](https://vercel.com) → Sign in
2. Click **"Add New Project"**
3. Scroll down to **"Import Third-Party Git Repository"** or use the CLI
4. Alternatively: just drag the project folder into the Vercel dashboard

## 🔗 Custom Domain (Optional)

1. In your Vercel project dashboard → Go to **"Settings"** → **"Domains"**
2. Add your custom domain (e.g., `sreesanth.dev`)
3. Update your domain's DNS as Vercel instructs
